Mengapa DisasterWatch Hadir?

Indonesia adalah laboratorium bencana. Kita butuh cara baru untuk memahami dan mengantisipasinya.

Tantangan Saat Ini

  • Data bencana tersebar dan sulit divisualisasikan.
  • Rekomendasi mitigasi seringkali bersifat umum, tidak spesifik per wilayah.
  • Kurangnya alat simulasi prediksi dampak yang mudah diakses.

Solusi Kami

  • Dashboard interaktif dengan 44.000+ data tervalidasi.
  • Klasterisasi risiko (K-Means) untuk rekomendasi yang tepat sasaran.
  • Simulasi Machine Learning untuk prediksi korban dan kerugian.

Kenali Fitur Unggulan Dashboard

Bukan sekadar tampilan visual, ini adalah alat kerja untuk memahami pola kebencanaan secara mendalam.

Eksplorasi Data Tanpa Batas.

DisasterWatch mengintegrasikan data BNPB dengan model Machine Learning untuk memberikan gambaran menyeluruh tentang risiko bencana di Indonesia.

  • Overview Komprehensif Ringkasan KPI kebencanaan, tren bulanan, dan komposisi bencana dalam satu layar.
  • Peta Wilayah Interaktif Sebaran titik bencana dan tingkat risiko di 38 provinsi dengan visualisasi Leaflet.
  • Analitik Tren & Prediksi Prediksi jumlah kejadian hingga 12 bulan ke depan dengan algoritma XGBoost.
  • Simulasi Mitigasi & Klaster Simulasikan dampak bencana dan dapatkan rekomendasi tindakan preventif.
Bencana di Indonesia Dari banjir hingga erupsi, dashboard membantu memetakan risiko secara nasional.

Pertanyaan yang Sering Diajukan

Beberapa hal yang mungkin ingin kamu ketahui sebelum menggunakan DisasterWatch.

Dari mana data kebencanaan ini berasal?
Data bersumber dari Badan Nasional Penanggulangan Bencana (BNPB) melalui platform DIBI (Data Informasi Bencana Indonesia). Data mencakup laporan kejadian dari tahun 2015 hingga 2026.
Apakah dashboard ini bisa diakses secara gratis?
Ya, DisasterWatch sepenuhnya gratis dan open-source. Kami percaya bahwa akses terhadap data kebencanaan adalah hak semua orang untuk bersama-sama membangun Indonesia yang lebih tangguh.
Bagaimana cara model ML memprediksi korban jiwa?
Kami melatih model Random Forest dengan data historis BNPB yang mencakup berbagai fitur seperti jenis bencana, lokasi, dan kepadatan penduduk. Model ini kemudian memperkirakan tingkat dampak (ringan, sedang, berat) dan mengestimasi jumlah korban berdasarkan median data historis.
Apakah data di sini sudah mencakup semua provinsi di Indonesia?
Saat ini dashboard mencakup 38 provinsi di Indonesia. Kami terus melakukan pembaruan data secara berkala untuk memastikan akurasi dan cakupan yang maksimal.
Bagaimana cara dashboard berjalan tanpa server backend?
Kami menggunakan pendekatan zero-backend. Semua model Machine Learning (Random Forest) telah dikonversi ke dalam format JavaScript. Jadi, saat pengguna melakukan simulasi, komputasi prediksi terjadi langsung di browser pengguna (client-side) tanpa perlu mengirim data ke server.
Apakah data saya aman saat menggunakan simulasi?
Sangat aman. Karena dashboard berjalan sepenuhnya di browser Anda, tidak ada data input (seperti jenis bencana atau provinsi yang dipilih) yang dikirim atau disimpan ke server mana pun. Semua proses simulasi bersifat privat.
Seberapa sering data dan model diperbarui?
Pembaruan data dilakukan secara berkala dengan menarik data terbaru dari Geoportal BNPB. Setelah data baru di-preprocessing dan model di-train ulang, file JSON dan JS akan di-generate ulang, dan dashboard akan ter-update secara otomatis melalui sistem CI/CD (Vercel).
